Software Recommendations

This page contains a collection of software and tools that may be useful for studying physics, conducting experiments, programming, writing scientific documents, and taking notes.

Tracker

Tracker is a free video-analysis tool that allows students to analyze an object's motion, trajectory, and other physical properties. It does not require external equipment such as a motion sensor. You can simply import a video and begin analyzing the motion of objects within it.

Tracker Official Website & Download

Physics Toolbox

Physics Toolbox is a collection of applications that uses sensors available in smartphones and other devices to measure physical quantities such as pressure. It can be particularly useful for physics experiments and demonstrations.

Physics Toolbox Official Website

Physics Toolbox Sensor Suite for iPhone and iPad

Python

Python is a powerful programming language commonly used in scientific computing and research. It is useful for numerical calculations, data analysis, visualization, simulations, and many other scientific applications.

Download Python

Python Documentation and Tutorials

Anaconda

Anaconda is a Python distribution commonly used for scientific computing and data science. It provides convenient access to tools such as Jupyter Notebook and JupyterLab and includes many commonly used scientific Python packages.

Anaconda Official Website

LaTeX

LaTeX is a document-preparation system widely used for scientific and mathematical writing. It is particularly useful for lab reports, research papers, group projects, and documents containing equations.

LaTeX Official Website

LaTeX Tutorial

Typst

Typst is a modern document-preparation system with functionality similar to LaTeX. It provides fast compilation and can be useful for writing lab reports and other scientific documents.

Typst Official Website

Typst Tutorial

OneNote

OneNote is note-taking software developed by Microsoft. It allows users to organize notes into multiple notebooks and provides a flexible canvas for handwritten and typed notes. It can be particularly useful for organizing class notes.

Microsoft OneNote

BetterZip

BetterZip is an archive-management application for macOS. It allows users to view and modify files inside formats such as ZIP, TAR, TGZ, TBZ, TXZ, and RAR without first extracting the entire archive.

BetterZip Official Website
